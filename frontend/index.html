Конфигурация FastAPI & API Module

Архитектурное разделение UI и API:

Все сетевые вызовы инкапсулированы в модуле window.FreedomAPI. Синтетические диалоги доступны в демонстрационном режиме.

Пример: http://127.0.0.1:8000 или http://api.dialog.internal

Спецификация используемых эндпоинтов:

GET /api/conversations
GET /api/conversations/{id}
GET /api/checklists
POST /api/checklists/{id}/versions
POST /api/evaluations (body: conversation_id, checklist_id, checklist_version)
GET /api/evaluations/{id} (поллинг статуса каждые 2-3 сек)
POST /api/appeals
GET /api/appeals
POST /api/appeals/{id}/review
